# WanderWise

WanderWise is a web application designed to help users explore and compare cities worldwide, facilitating travel planning through an interactive and modern interface.

## Project Description

The project uses **Vite** as its build tool, allowing for fast and efficient development. The application focuses on providing detailed information about cities, enabling users to discover new destinations and contrast options for their next trip.

### Key Features:
- **City Exploration:** Interface to discover various cities.
- **Comparison:** Tools to compare data between different destinations.
- **Responsive Design:** Adapted for different screen sizes using modern CSS.

## How to Get it Running

To run this project locally, follow these steps:

### Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation and Execution

1. **Clone the repository or navigate to the project folder:**
   ```bash
   cd WanderWise
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
   Once executed, Vite will provide a URL (typically `http://localhost:5173`) that you can open in your browser to view the application in real-time.

### Other Useful Commands

- **Build for production:** 
  ```bash
  npm run build
  ```
  This will generate an optimized version of the site in the `dist/` folder.

- **Preview the production build:**
  ```bash
  npm run preview
  ```

- **Format the code:**
  ```bash
  npm run format
  ```

- **Run tests:**
  ```bash
  npm test
  ```
